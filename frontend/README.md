# InfraPulse Frontend

React + Vite + TypeScript package (JSX components) with Leaflet mapping.

```bash
npm install
npm run dev
```

Open the URL Vite prints (typically `http://localhost:5173`). The API must be running at `http://127.0.0.1:8000`, or set `VITE_API_BASE_URL` before starting the frontend.

The map uses OpenStreetMap tiles and requires internet access when viewed. API/scoring data works locally from the backend.
