# InfraPulse Product Overview

**Goal:** Identify the gap between rural infrastructure availability and reliable service, then support human-led intervention planning.

**Primary SDG:** 9 — Industry, Innovation and Infrastructure.

**MVP user journey:** Dashboard → Map → Village Profile → Priority Ranking → Scenario Lab → Methodology / CSV export.

**Core differentiator:** provenance-aware multi-sector component scores; explicit availability–reliability gap; explainable population/criticality-based priority; non-destructive, user-controlled what-if simulation.

**Evidence boundary:** all seed metrics and pins are synthetic. Real use requires verified, time-aligned, licensed sources and local validation. Weights are prototype assumptions, not official standards.
